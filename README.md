# benchie.world

The public website for Benchie: landing page, privacy policy and terms. The app itself lives in a private repo.

- `web/` is what gets published (GitHub Pages, custom domain benchie.world).
- `tools/weekly/` draws the Bench of the week card every Monday into `web/week/` (see `.github/workflows/site.yml`).

Only website files belong here. This repo is public.
